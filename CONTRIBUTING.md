# Contributing

1. Create a focused branch.
2. Run `npm install` and `npm run dev`.
3. Keep copy bilingual, neutral, and source-linked.
4. Never add unsupported figures, invented quotations, unnecessary personal data, or unlicensed media.
5. Preserve validation, accessibility labels, and the “integrity is not truth” warning.
6. Run `npm run lint`, `npm run test`, and `npm run build`.
7. Describe source review, privacy impact, and screenshots in the pull request.

Report security or sensitive-data concerns privately to the future repository owner; do not place personal records in public issues.
